## Game files

The game plays with its own art, sounds, texts and rules only, which are in this folder (Assets/, ModernArt/, Lua/, Text/, Civilopedia/). It needs no other game's files.

## What is that?

- Fonts/ - Fonts for Godot text
- main_menu.tscn & MainMenu.cs - The startup scene and main menu
- C7Game.tscn & Game.cs - An early prototype map view accessible from the main menu
