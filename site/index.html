Download & install Server setup

Windows setup

  1. Click windows.zip above to download it.
  2. Open your Downloads folder, right-click windows.zip and choose Extract All…, then click Extract.
    Don't open the game from inside the zip without extracting it first, or it won't find its files.
  3. A new folder opens. You can move this whole folder anywhere you like, such as your Desktop or Documents.
  4. Inside the folder, double-click the file with the game's icon to play.
  5. If a blue box says "Windows protected your PC", click More info, then Run anyway. You only need to do this once.

Tip: for a desktop shortcut, right-click the game file, choose Show more options → Send to → Desktop (create shortcut).

If the game closes as soon as it opens

Windows 11's Smart App Control is probably blocking it. To check, open Windows Security from the Start menu and go to App & browser control → Smart App Control settings. If it says On, the game can't run on this PC yet.

You can turn Smart App Control off there, but once it's off, it can't be turned back on without resetting Windows. It's your choice. A version that works with it on is being worked on.

Mac setup

  1. Click mac.zip above to download it. Your Mac unzips it into a folder in Downloads.
  2. Keep everything in that folder together. Move the whole folder wherever you like, but don't drag just the app into Applications, because it needs the other files next to it.
  3. The first time, right-click (or Control-click) the app and choose Open, then click Open again.
  4. If your Mac only offers Done or Move to Trash, click Done. Then open System Settings → Privacy & Security, scroll down and click Open Anyway next to the message about the game.
  5. After that, double-click the app as normal.

Linux setup

  1. Click linux.tar.gz above to download it.
  2. Right-click it in your file manager and choose Extract Here.
  3. Open the new folder and double-click the file ending in .x86_64. If nothing happens, right-click it, open Properties, turn on Allow executing file as program, and try again.

Updating

Download the newest file from this page and extract it in place of the old folder. Your settings are kept.

Playing with friends? See Server setup.

Hosting a game

There's no separate server to install: one player hosts the game on their own computer, and everyone else joins it. The host's computer runs the game for everybody, so it has to stay on with the game open until you stop playing.

Before you start

  • Everyone needs the same version of the game. If in doubt, everyone downloads again from this page.
  • Pick a computer that will stay on for the whole session as the host. One plugged into the router with a cable is ideal.

Start a new game

  1. From the main menu, choose Host LAN Game, then New Game.
  2. Set up the world as usual.
  3. On the player setup screen, tick Human on one rival for each person joining. Their civilization shows as Player's choice: they pick it themselves in the lobby.
  4. Start the game. Instead of the map, you'll see the lobby.

Host a saved game

  • Choose Host LAN Game, then Load Game, and pick a game saved with more than one human player.
  • To carry on from last time, choose Resume Last LAN Game. It goes back to the start of the last turn, and players get their seats back when they reconnect.

In the lobby

  1. The lobby lists this computer's addresses. Players on the same network usually see your game listed and don't need them. If they can't, read out the one that starts with 192.168. or 10.
  2. Optionally set Time per turn. When a player runs out of time, their turn ends for them.
  3. Wait until every human seat is taken. When the lobby says Everyone is here, click Start Game.
Keep the game open on the host's computer. If the host quits or loses its connection, the game stops for everyone. A player who drops out can rejoin the game in progress and take their seat back.

Joining a game

  1. From the main menu, choose Join LAN Game and type your name.
  2. Click Join next to the host's game under Games on your network. If it isn't listed, type the host's address into Or join by address.
  3. Click Take Seat on an open seat. In a new game, choose your civilization, then wait for the host to start.
  4. Rejoining a game in progress: tick Take next to your seat, then click Join Game.

To follow along without playing, click Watch instead of Join.

Several players at one computer

People sharing a computer can join together and take turns at it, as in a hotseat game:

  1. Join the game once, then click Take Seat on a seat for each person at the computer.
  2. Type each player's name in the box beside their seat.
  3. In a new game, click Choose Civilization beside a seat to pick that player's civilization.

During the game, a screen asks the right person to take over before each of their turns.

Ports and firewalls

The host uses TCP port 47777 for the game, and UDP port 47778 so others on the network can find it. Players joining don't need to open anything.

Playing together on the same network

  • Everyone needs the same version. If in doubt, download again from this page.
  • On Windows, the first time someone hosts a game, Windows asks about network access. Click Allow (with Private networks ticked). If you clicked Cancel by mistake, other players won't be able to find or join your game.
  • Everyone must be on the same Wi-Fi or home network. Guest Wi-Fi networks often block this.

Playing together over the internet

Friends in other homes can join using Tailscale, a free app that links your computers as if they were on the same network. Each person sets it up once.

Everyone

  1. Download Tailscale from tailscale.com/download, install it, and sign in (a Google, Microsoft or Apple account works).
  2. Make sure everyone has the same version of the game from this page.

The person hosting

  1. Go to login.tailscale.com/admin/machines, click … next to your computer and choose Share…. Send the invite link to each friend. They open it and click Accept.
  2. Start the game and host a game as usual. The game lists this computer's addresses: tell your friends the one that starts with 100. (for example 100.101.102.103).
  3. When Windows asks about network access, click Allow.

Friends joining

  1. In the game, go to joining a game. Games over the internet aren't listed automatically, so type the host's 100. address into "Or join by address" and press Enter.
  2. Pick your seat as usual.

If friends can't connect: check that Tailscale says Connected on both computers, and that the host's computer appears in the friend's Tailscale app. If it still fails, the host's Windows may be treating Tailscale as a public network: open Windows Security → Firewall & network protection → Allow an app through firewall, and tick both Private and Public for the game.
