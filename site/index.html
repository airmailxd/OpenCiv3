Download & install Play with friends

With the launcher

The launcher is a small program that downloads the game for you and starts it. When there's a new version, it fetches only the parts that changed. The game's pictures rarely change, so most updates are much smaller than the whole game.

The launcher comes packed in a zip file: a bundle of files squeezed into one, a bit like a suitcase. You need to unpack it first.

On Windows

  1. Click the Windows launcher above. It saves into your Downloads folder.
  2. Open your Downloads folder. Right-click the file, choose Extract All…, then click Extract. You get a folder called OpenCiv3. You can move it anywhere you like, such as your Desktop or Documents. The game will go in this folder too.
  3. Inside it, double-click OpenCiv3 Launcher. If Windows shows a blue box saying "Windows protected your PC", click More info, then Run anyway.
  4. Click Install. The first time, this downloads the whole game, which takes a few minutes.
  5. Click Play.

If the game closes straight away, see the note about Smart App Control further down this page.

On a Mac

  1. Click the Mac launcher above. Your Mac downloads it and unpacks it into a folder in Downloads by itself.
  2. The first time, don't double-click. Instead right-click OpenCiv3 Launcher (or hold Control and click), choose Open, then click Open again. If your Mac only offers Done, click it, then open System Settings, click Privacy & Security, scroll down, and click Open Anyway.
  3. The launcher shows the Game folder it will install into. To put the game somewhere else, click Choose folder….
  4. Click Install, and when it's done, Play. The launcher gets the game approved by your Mac itself, so there's nothing to type in Terminal.

On Linux

  1. Click the Linux launcher above, then right-click the file in your file manager and choose Extract Here.
  2. Open the new OpenCiv3 folder and double-click OpenCiv3-Launcher.x86_64. If nothing happens, right-click it, choose Properties, switch on Allow executing file as program, and try again.
  3. Click Install, and when it's done, Play.

Updating

Start the game from the launcher. When there's a new version, it says so: click Update, then Play. Without an internet connection, Play still starts the version you have.

Already have the game from a whole-game download? Put the launcher in the game's folder (next to the game and its Assets folder) and open it. It checks the files you already have and only downloads what's new.

Or download the whole game

If you'd rather not use the launcher, each version is also a single download with everything in it.

On Windows

The game comes packed in a zip file. You need to unpack it before playing.

  1. Click the Windows download above (a file named like openciv-windows-0.7.6.zip). It saves into your Downloads folder.
  2. Open your Downloads folder. Right-click that file, choose Extract All…, then click Extract. This unpacks it into a normal folder, which opens by itself.
    Don't skip this step. The game won't start properly from inside the zip file.
  3. You can move that folder anywhere you like, such as your Desktop. Always keep everything inside it together.
  4. Inside the folder, double-click the file with the game's picture on it. The game starts.
  5. The first time, Windows may show a blue box saying "Windows protected your PC". This only means Windows hasn't seen this game before. Click More info, then Run anyway. You only do this once.

Tip: to start the game from your Desktop, right-click the game file, choose Show more options, then Send to, then Desktop (create shortcut).

If the game closes straight away

Windows 11 has a safety feature called Smart App Control that can block new games. To see if it's on: click Start, type Windows Security and open it, then click App & browser control, then Smart App Control settings. If it says On, the game can't run on this computer yet.

You can switch Smart App Control off on that same screen, but once it's off, you can't switch it back on without resetting Windows. If you're unsure, leave it on and wait: a version that works with it is on the way.

On a Mac

  1. Click the Mac download above (a file named like openciv-mac-0.7.6.zip). Your Mac downloads it and unpacks it into a folder in Downloads by itself.
  2. Keep everything in that folder together. You can move the whole folder, but don't drag only the game into Applications: it needs the other files next to it.
  3. The first time, don't double-click. Instead right-click the game (or hold Control and click), choose Open, then click Open again. This tells your Mac you trust it.
  4. If your Mac only offers Done or Move to Trash, click Done. Then open System Settings, click Privacy & Security, scroll down, and click Open Anyway next to the message about the game.
  5. From then on, double-click the game like anything else.

If the game closes straight away

On some newer Macs the game closes the moment it starts, or won't open at all, even after Open Anyway. You can fix this by telling your Mac to approve the game again:

  1. Open Terminal: press Command+Space, type Terminal, and press Return.
  2. Type cd and a space. Then drag the game's folder (the one with the game and its other files inside) from Finder onto the Terminal window, and press Return.
  3. Copy this line, paste it into Terminal, and press Return:
    codesign -d --entitlements :- OpenCiv3.app > /tmp/ent.plist
  4. Then copy this line, paste it, and press Return:
    codesign --force --deep --options runtime --entitlements /tmp/ent.plist -s - OpenCiv3.app
  5. Close Terminal and double-click the game. If your Mac asks again, do the Open Anyway step above once more.

You only need to do this once for each new version you download.

On Linux

  1. Click the Linux download above (a file named like openciv-linux-0.7.6.tar.gz).
  2. Right-click it in your file manager and choose Extract Here.
  3. Open the new folder and double-click the file whose name ends in .x86_64. If nothing happens, right-click it, choose Properties, switch on Allow executing file as program, and try again.

Getting a newer version

With the launcher, click Update in it. Otherwise, download again from this page and unpack it the same way, replacing the old folder. Your settings are kept either way.

How playing together works

One person hosts the game: their computer runs it for everyone. Everyone else joins from their own computer. Each player has a seat, which is simply their place in the game, like a chair at a card table.

Nothing extra needs installing. Everyone just needs the game from this page, and the same version of it. If in doubt, everyone downloads it again.

The host's computer must stay on, with the game open, until everyone has finished. If it's switched off or the game is closed, the game stops for everyone.

If you're hosting a new game

  1. On the game's first screen, click Host LAN Game, then New Game. ("LAN" just means the computers in your home.)
  2. Choose the map and settings as you would for a game on your own.
  3. On the screen where you pick the other civilizations, tick Human once for each person joining. Each of those players picks their own civilization later.
  4. Click to start. Instead of the map, you'll see a waiting room (the game calls it the lobby) where you wait for everyone to arrive.
  5. When the screen says Everyone is here, click Start Game.

In the waiting room you can also choose Time per turn. If someone takes longer than that, their turn ends by itself.

If you're carrying on an old game

  • To continue where you all left off last time, click Host LAN Game, then Resume Last LAN Game. It goes back to the start of the last turn. Everyone gets their old seat back when they join.
  • To pick a saved game yourself, click Host LAN Game, then Load Game.

If you're joining

  1. On the game's first screen, click Join LAN Game and type your name.
  2. The host's game should appear in a list. Click Join next to it.
  3. Click Take Seat next to a free seat.
  4. In a new game, pick your civilization. Then wait: the game starts by itself when the host is ready.

To just watch without playing, click Watch instead of Join.

If the host's game isn't in the list: ask the host to read out the number shown on their screen that starts with 192.168. or 10. (it looks like 192.168.1.20). This is their computer's address, which tells your computer where to find it. Type it into the box marked Or join by address and click Join.

If you got disconnected: join again the same way. Tick Take next to your old seat, then click Join Game, and you're back in.

Two or more people sharing one computer

People sitting at the same computer can play together, passing it around on their turns:

  1. Join the game once, then click Take Seat once for each person at the computer.
  2. Type each person's name in the box beside their seat.
  3. In a new game, click Choose Civilization next to each seat to pick that person's civilization.

During the game, before each turn, the screen goes dark and says whose turn it is, so the others can look away. That person then clicks Begin Turn.

Playing in the same house

  • Every computer must be on the same Wi-Fi, the same one you use for the internet at home. "Guest" Wi-Fi often doesn't work for this.
  • On Windows, the first time someone hosts, a box asks whether to let the game use the network. Click Allow. If you clicked Cancel by mistake, see the note at the bottom of this page.

Playing with people in other houses

Computers in different houses can't see each other on their own. A free app called Tailscale fixes that: it connects your computers as if they were all in the same house. Each person sets it up once.

Everyone

  1. Go to tailscale.com/download, download Tailscale and install it.
  2. Open it and sign in. Your usual Google, Microsoft or Apple account works.

The host

  1. Go to login.tailscale.com/admin/machines. You'll see your computer listed. Click the … next to it and choose Share…. This gives you an invitation link.
  2. Send that link to each friend, for example by email or text message. They open it and click Accept.
  3. Host the game as usual. The waiting room shows some numbers: tell your friends the one that starts with 100. (for example 100.101.102.103).

Friends joining

  1. Click Join LAN Game. The host's game won't appear in the list this time, and that's normal.
  2. Type the host's number starting with 100. into the box marked Or join by address, and click Join.
  3. Take your seat as usual.

Can't connect? Check that Tailscale says Connected on both computers, and that the host's computer appears in the friend's Tailscale app.

If others still can't find or join the host

Windows on the host's computer may be blocking the game. On the host's computer: click Start, type Windows Security and open it. Click Firewall & network protection, then Allow an app through firewall, then Change settings. Find the game in the list and tick both boxes next to it (Private and Public), then click OK.

For whoever looks after your home internet: the host receives connections on TCP port 47777, and answers searches for games on UDP port 47778. People joining don't need anything opened.

Run your own online server

Games played over the internet with a join code (like KQ7-4MZ) pass through an online server, also called a relay. It doesn't run the game; it just passes messages between the host and the people joining. Anyone can run one for their friends or group.

You need a small computer on the internet that's always on. It can be free (Oracle Cloud's free tier) or cost a few euros a month (Hetzner Cloud), plus a free name for it such as one from DuckDNS. Setting it up takes about half an hour, typing a few commands the guide gives you.

Read the step-by-step setup guide

Once it's running, tell your players its name (like myrelay.duckdns.org). Each player types it once in the game's Settings, under Online, in the box marked Relay server. Or the host types it in the waiting room before clicking Host Online, and shares the join code, which then includes the server's name.
