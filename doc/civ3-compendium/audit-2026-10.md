# Engine audit against the compendium, October 2026

Each compendium section was compared with the engine code. The sourced discrepancies were fixed, with a
test each and the source quoted in a code comment (commits `812b79d6` to `8dd1c95c`). This file lists
what is still open.

## Waiting on the project owner

1. **Industrious city-tile shield.** The Civilopedia (`GCON_Strengths`) says "the center city square of all
   cities produces extra shields in cities and metros". civ-wiki.de (Stadtfeldertrag), which the code
   cites, gives the extra shield only at size 13 and up. The code keeps metropolises only.
2. **Resource depletion.** The C3C editor help says the chance "is not influenced by use; a resource can
   disappear even if a civilization has never used the resource". The code lets only resources in use run
   out, following CFC tests (`ResourceDepletion.cs`).
3. **Pop-rush rounding.** The code rounds to the nearest citizen (owner's decision). DBear's CFC post says
   one citizen "per 20 shields or fraction thereof", which rounds up.
4. **AI luxury slider.** Ision (CFC 92917) says the Civ3 AI "will NOT use the luxury slider". The AI here
   raises it to 50% when most cities are unhappy. This is an AI heuristic, so changing it needs an AI trial.
5. **AI government changes at war.** Players report the Civ3 AI moving to Monarchy or Communism during
   long wars (chiefpaco, hedged). `GovernmentAI` never switches while at war, except out of Despotism.
6. **Techs across eras.** Quintillus says trades and the Great Library cross eras. The code offers only
   techs of the current era or earlier.

## Skipped: sources too thin

- The AI-human trade markup table (TheNiceOne) is only summarized in the compendium, with no Demigod or
  Sid rows, and the tech price function is UNVERIFIED.
- Rate of fire against buildings, citizens and improvements: no source says how shots pick targets.
- Hut and camp messages in Civ3's wording: the engine has no barbarian tribe names yet.

## Small fixes not yet done

- An AI that doesn't found its capital on turn 1 never gets its difficulty start units
  (`Player.MaybeSpawnBonusUnits`). The fix needs a saved "units given" flag.
- The resistance government modifier covers 6 governments from a CFC article. The BIQ has a full 8×8
  `ResistanceModifier` table that also covers Feudalism and Fascism.
- Hoover Dam needs a river at the city tile; the Civilopedia says within the city radius. Iron Works
  accepts Iron and Coal from anywhere, not just the city radius. Check the BIQ flag bit first
  (`QueryCiv3/BiqSections/Bldg.cs`).
- The Great Library grants a whole prerequisite chain in one turn. justanick says it makes one pass in
  editor order.
- A city with one turn left on its build can still switch to a wonder (Travathian says it can't).
- Units can join an army in any of the owner's cities; README-V says only the city where it was built.
  Restricting that needs a saved origin city.

## Not implemented (sourced Civ3 features)

- **Citizens and governments:** assimilation of foreign citizens (BIQ `AssimilationChance`, 1–4% a turn by
  government); Fascism's Forced Resettlement and Xenophobic flags; riots destroying improvements in
  disorder (`ChanceOfRioting`); prolonged disorder overthrowing the government; mobilization; global
  warming.
- **Map and combat:** bombardment making craters; plague; barricades blocking movement; colonies overrun
  by barbarians.
- **Espionage and diplomacy:** the "carefully" and "safely" espionage levels; AI sabotage and propaganda
  missions; AI loans.
- **Attitude:** many smaller terms (broken alliances, razing, a common enemy, culture-flip offers,
  territory warnings).
