# Civ3 rules compendium

How Civilization III plays, written to guide the engine's rules and AI. It covers the base game (1.29f),
Play the World (1.27f) and Conquests (1.22), with Conquests as the target. Scenarios, mods and the special
Conquests game modes (Regicide, Mass Regicide, Elimination, Capture the Flag/Princess, victory-point
games) are left out.

Every rule cites its source: a CivFanatics or Apolyton thread, a Firaxis statement, a patch readme, or
the Civ3 Complete install (Civilopedia.txt, the editor help, labels.txt, and `conquests.biq` read with
QueryCiv3). Each section ends with what is **Disputed** and what is **UNVERIFIED**. Don't treat those as
rules: an engine choice made for one of them says so in a code comment, and the project owner's own
rulings take precedence over forum sources.

Quotes taken through a web summarizer may differ slightly from the page. Check the page before relying
on exact wording.
