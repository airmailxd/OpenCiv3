# Civ3 mechanics source inventory

A catalogue of the CivFanatics (CFC) and Apolyton sources on Civilization III game mechanics, made so later
research passes can read them all. Scope is the same as the compendium: base game 1.29f, Play the World
(PTW) 1.27f and Conquests (C3C) 1.22. Scenarios, mods (C3X, Rise and Rule, CCM and so on) and the special
Conquests game modes are out of scope. A few mod or scenario threads are listed only where they document the
stock game's engine, and they say so.

Built 2026-10-20. Every URL already cited in sections 01 to 08 of the compendium is listed here and marked
**already cited**.

## How to read an entry

`Title` | URL | author | version | what it covers | status

- **Version**: `V` = vanilla (base game), `PTW`, `C3C`. A `?` means it wasn't stated in the index. `era` gives
  the year when the version wasn't stated. Rough CFC thread-ID eras: below about 27000 is 2001-02 (vanilla,
  before 1.29f); 27000-60000 is 2002-03 (vanilla 1.29f / PTW); 60000-105000 is 2003-04 (PTW 1.27f / C3C
  1.0-1.22); above that is later C3C play.
- **Status**:
  - **already cited**: the compendium cites it.
  - **not yet read**: found in an index or a search and not opened.
  - **fetch failed (code)**: the page couldn't be fetched.
  - **read in deep pass (reading-log-NN)**: read in the October 2026 deep pass; what it gave is in that section's reading log.
  - **not Civ3 (deep pass)**: turned out to be about another Civilization game; not used.
- "covers" is taken from the title, the index blurb or a search snippet. It isn't a reading of the page.

## URL notes

- Old CFC links (`showthread.php?t=N`, `showthread.php?threadid=N`) resolve to `forums.civfanatics.com/threads/N/`.
- War Academy articles exist twice: as a web page under `civfanatics.com/civ3/strategy/...` (or `civfanatics.com/?p=N`)
  and as the forum thread they came from, in "Civ3 Strategy Articles". The forum thread holds the follow-up
  discussion and corrections.
- The codehappy.net Apolyton mirror (`codehappy.net/apolyton/threads/<id>-<page>.htm`) uses different thread IDs
  from apolyton.net for most forums. Known pairs: codehappy 31760 = apolyton 42626 (Distilled tips), codehappy
  31299 = apolyton 42123 (Propaganda chances), codehappy 52543 = apolyton 64407 (combat with retreat odds),
  codehappy 104623 = apolyton 121330 (Heroic Epic). Civ3-General IDs seem to match (51715 on both). The
  mirror covers threads up to Dec 2010 and splits each thread into one file per page. `-1.htm` is page 1, and
  the page count is shown as "pp".
- apolyton.net archive threads take the form `apolyton.net/forum/miscellaneous/archives/<forum>/<id>-<slug>`.
